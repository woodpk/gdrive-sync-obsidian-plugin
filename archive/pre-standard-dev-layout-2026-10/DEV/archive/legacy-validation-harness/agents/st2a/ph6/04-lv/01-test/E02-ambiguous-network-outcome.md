# E02 — Ambiguous Network Outcome After Remote Mutation

Follow the shared protocol and OBS-01 gate.

Use a disposable fixture and an approved controllable network interruption to lose the client response after a remote mutation may have occurred. Do not directly edit Drive to simulate success.

PASS: the operation remains uncertain until remote reality is observed; retry/recovery does not create a duplicate or overwrite valid content; authority commits only after verification.

If the response-loss point cannot be controlled safely, report BLOCKED rather than approximating it.
