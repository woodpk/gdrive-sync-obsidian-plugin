# F03 — Disable / Uninstall / Device Unlink Safety

Follow the shared protocol. Back up local plugin settings/state first.

Using the secondary/iOS device where practical, verify in sequence that disabling the plugin, uninstalling/reinstalling it, and device deauthorization/unlink do not delete local vault content or shared remote content and do not impair the other valid device.

Reinstall/reconnect only through normal supported flow.

PASS: shared/local data remain intact, remote identity is not silently replaced, and re-entry requires appropriate validation/reconciliation.

Stop. This is the final ordinary live-validation task in this suite.
