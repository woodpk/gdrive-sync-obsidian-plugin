# State Handoffs

Purpose: concise continuity artifacts needed to transfer current execution context between engineering sessions or agents.

Allowed artifact classes: bounded current handoffs that summarize active state, immediate dependencies, and next action.

Prohibited artifact classes: permanent product/architecture decisions, accumulated transcript history, full build journals, PHX-CI results, or task-prompt libraries.

Authority status: handoffs aid continuity but do not override repository reality, target-system authority, or the decision register.

Naming: use stable lowercase kebab-case descriptive filenames.
