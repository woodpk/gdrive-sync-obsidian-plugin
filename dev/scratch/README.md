# dev/scratch/

Purpose: non-authoritative temporary engineering working space.

Allowed artifact classes: temporary analyses, inventories, migration manifests, intermediate calculations, and other working material that is not required as durable authority or continuity state.

Prohibited artifact classes: product or architecture decisions, canonical planning, current project state, completed review authority, PHX-CI historical run evidence, and any artifact that later work must depend on permanently.

Authority status: **non-authoritative**. Useful durable content must be promoted to its canonical standardized directory before later work depends on it.

Naming: use descriptive lowercase kebab-case names unless a governing standard requires another exact name.
