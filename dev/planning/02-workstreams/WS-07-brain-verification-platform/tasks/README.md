# WS-07 Durable Future Tasks

Purpose: persist only future task contracts that genuinely need to survive between sessions.

Allowed artifact classes: bounded future WS-07 task contracts that have not yet executed and whose durable scope is not adequately represented by the workstream decomposition alone.

Prohibited artifact classes: completed prompts, historical task transcripts, generic prompt libraries, current-state journals, review output, or executable task instructions that have not been rebound to current repository reality.

Authority status: task files are subordinate planning artifacts. They do not override the target-system specification, decision register, WS-07 architecture, current repository, or current external engineering protocol.

Naming: group related future tasks by bounded work package. The retained `s09/` contracts remain `PREPLANNED / NOT-YET-EXECUTABLE` until a supervisor re-grounds and binds them immediately before execution.
