# Verification Planning

Purpose: define whole-project verification strategy and Stage-1 completion evidence.

Allowed artifact classes: `verification-plan.md`, `stage-1-completion-audit.md`, and directly supporting planning material.

Prohibited artifact classes: actual PHX-CI run output, terminal logs, task-specific independent validation harnesses, or review reports.

Authority status: verification planning is derived planning, not an independent executable validation authority.

Naming: use the canonical filenames defined by the governing standard.
