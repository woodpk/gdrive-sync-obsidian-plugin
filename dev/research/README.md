# Research

Purpose: research, source analysis, experiments, and durable reasoning used to inform engineering or product decisions.

Allowed artifact classes: bounded research reports, source analyses, technical experiments, comparative evaluations, and durable reasoning that remains useful after the immediate task.

Prohibited artifact classes: accepted product/architecture decisions, current project state, PHX-CI run output, implementation prompts, or temporary scratch material.

Authority status: research is evidence, not governing authority merely because it exists here.

Naming: research-topic directories use lowercase kebab-case descriptive names.
