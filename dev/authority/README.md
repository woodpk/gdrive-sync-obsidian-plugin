# Authority

Purpose: durable repository-controlled governing material.

Allowed artifact classes: the canonical decision register, authority map, external-authority references, repository-level documentary contracts, project-specific governance rubrics and locks, and authority reconciliations.

Prohibited artifact classes: transient project status, build-session journals, PHX-CI run output, scratch work, implementation transcripts, and completed review reports as substitutes for accepted decisions.

Authority status: artifacts in this directory may be authoritative according to their own role and precedence. This README is navigation only and creates no decisions.

Naming: use the canonical filenames and subdirectories defined by the governing development standard.
