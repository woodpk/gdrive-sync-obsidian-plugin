# Governance Rubrics

Purpose: durable project-specific evaluation rubrics used by authorized engineering or review workflows.

Allowed artifact classes: stable rubrics and scoring/evaluation criteria explicitly adopted by project governance.

Prohibited artifact classes: transient review output, test results, task prompts, or implementation logs.

Authority status: a rubric governs only when adopted through the authority system; location alone does not make it authoritative.

Naming: lowercase kebab-case descriptive filenames.
