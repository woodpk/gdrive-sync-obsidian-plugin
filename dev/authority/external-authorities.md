Shared governing manuals remain external shared resources and are referenced here rather than copied into the repository.

## PHX-CI Test Authoring Request — PTAR v2.0 (Independent Test Lifecycle)

Canonical link: https://docs.google.com/document/d/16UzwNUhC-_0NyH48jIlTiNyWF4cwdHopvblBsFDoXrk/edit

Role: mandatory pre-build test authoring, fresh post-build blind assessment, separately authorized adversarial test authoring, isolated Git commits and immutable handoffs, PHX-CI-exclusive test execution by a distinct agent, and separate independent acceptance. GitHub persistence is canonical; ZIP archives and GitHub Actions are not substitutes.

## Use

These documents govern engineering process and repository-development organization. They do not replace repository-specific product intent, the target-system specification, or accepted project decisions. Later explicit user decisions remain authoritative where the governing process allows product authority to decide the matter.
