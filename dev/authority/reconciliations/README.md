# Authority Reconciliations

Purpose: record how authoritative decisions, contracts, transitions, or supersessions relate without creating a competing decision system.

Allowed artifact classes: authority-transition records, reconciliation analyses, supersession mappings, and cross-authority consistency records.

Prohibited artifact classes: new product decisions, implementation journals, test results, task prompts, or transient state.

Authority status: reconciliation records explain authority; material decisions themselves remain in the canonical decision register or other controlling authority.
