# Reviews

Purpose: completed independent or adversarial review outputs.

Allowed artifact classes: completed review reports and their directly supporting review artifacts, grouped by stable review identifier.

Prohibited artifact classes: product/architecture decisions, transient work notes, PHX-CI run archives, task prompts, or current-state tracking.

Authority status: review findings do not become governing authority merely by location. Material decisions resulting from review must be persisted through the authority system.

Naming: review directories use a stable review identifier followed by an optional kebab-case description.
